Description en Español:
Agrega un selector de cantidad y un botón "Comprar" nativo de WooCommerce
en el archivo de productos (shop, categorías, etiquetas y donde se use el
shortcode [products]), sin depender del tema xstore.

Funciona con el shortcode:
[products limit="12" columns="4" paginate="true" orderby="date"]

Características:
- Selector de cantidad nativo por producto en el loop de WooCommerce.
- Botón "Comprar" estilo botón nativo de WooCommerce.
- Agrega al carrito vía AJAX sin recargar la página.
- Mensajes de éxito/error por producto.
- Actualiza el contador del mini-carrito y totales automáticamente.
- Compatible con productos simples con stock.
- Diseño responsivo (móvil).

Instalación:
1. Descarga la carpeta del plugin o comprímela en .zip.
2. Ve a tu sitio WordPress (decotay.com.ar o tay.com.ar).
3. Plugins > Añadir nuevo > Subir plugin > elige el archivo .zip.
4. Instala y activa el plugin.
5. Verifica que WooCommerce esté activo.
6. En la página donde usas [products], aparecerá cantidad + Comprar bajo cada producto.

Desinstalación:
- Desactiva y elimina el plugin desde Plugins. No deja tablas en la base de datos.
